# Refinamento - Epico 1

## Visao do negocio
Fluxo mais simples possivel para demonstrar a arquitetura em camadas.

## Decisao tecnica
- Manter apenas um caso de uso
- Sem multincamadas desnecessarias
- Sem tecnologia cara ou complexa
- Usar apenas o que ja existe no ecossistema Spring Boot + Kotlin + Flyway

## Responsabilidades
- PO: definir o problema e o valor
- Backend: implementar a camada de aplicacao
- Tech Lead: validar a solucao simples
- QA: validar os cenarios principais

## Riscos
- Excesso de arquitetura para um exemplo didatico
- Complexidade desnecessaria para alunos iniciantes
